# Webscraper for Antler Next100 Cards

A Python script that scrapes data from the [Antler Next100](https://www.antler.co/next100) platform and creates a structured dataset of company information.

## Overview

This repository contains a web scraping tool designed to collect and organize information about ideas featured on the Antler Next100 platform. The scraper extracts details such as ideas title, descriptions to csv file.

## Features

- Automated data extraction from Antler Next100
- Structured data output
- Easy to use and maintain
- Respectful of website's robots.txt and rate limiting

## Getting Started

1. Clone this repository
2. Install required dependencies
3. Run the scraper
4. Access the collected data

## Requirements

- Python 3.x
- requsts
- BeasutifulSoup 
- csv
